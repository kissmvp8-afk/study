## 必须成立的规则

- Actor 不直接接收仿真真实身体线速度；该信息可供 Q 和速度监督使用。
- 平地 C 预期为 54，复杂地形预期为 241，但必须从实际配置校验，禁止静默截断或补齐。
- 速度监督标签沿用原 base_lin_vel 的 2.0 缩放；不能把缩放后的预测直接当成米/秒。
