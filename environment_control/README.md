负责机器人任务、观测与动作的物理含义，以及一轮结束前后的数据。

本目录下各小模块彼此平级。每个小模块包含两份 README，未来实现与验证文件也放在同一目录。按下表界定改动范围，再读取目标模块及依赖契约。
