## 实施目标与术语

从最近 5 帧中提取共享表示，再输出三维速度估计与 16 维隐藏特征。

术语先说明：隐藏特征：网络学到的数字描述，未必能逐个解释成具体物理量。前向计算：给定输入和参数，算出输出。

## 必须成立的规则

- 本模块定义网络前向计算，不自行决定优化器更新。
- 16 个隐藏特征没有逐个人工指定的物理意义。
- 策略更新时保持编码器梯度隔离；BatchNorm 的模式管理另由辅助学习明确处理。
