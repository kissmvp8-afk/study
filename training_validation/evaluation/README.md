## 实施目标与术语

用固定任务和可复查指标判断 SAC 是否学会控制，而非只看训练损失或一段视频。

术语先说明：对照实验：在明确相同的条件下比较两种方法。随机起点：训练中的随机初始化和采样序列。

## 必须成立的规则

- 验收阈值在获得 PPO 波动范围后、正式 SAC 比较前固定。
- 建议至少三个不同训练随机起点；演示一次成功不等于性能验证。
- 以各自原生仿真推理先比较，导出差异由 T05 单独检查。
