## 必须成立的规则

- 原基线目标环境为 Isaac Sim 5.1、Isaac Lab 2.3.0、Python 3.11；实际兼容性需安装验证。
- 论文候选：gamma=0.97、n=5、tau=0.003、初始 std=0.15、actor/Q lr=2e-4、alpha lr=2e-5；所有参数可查。
- 工程入口配置可放根目录；实现与验证仍放所属小模块，避免新增第五个业务大模块。
