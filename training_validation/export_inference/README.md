## 实施目标与术语

让导出的 Actor 在相同观测与历史下，产生与训练内推理一致的动作。

术语先说明：导出：把训练框架中的模型转换成便于运行的文件。推理：使用固定参数算动作，不进行训练更新。

## 必须成立的规则

- 历史输入已含当前帧时不能再次追加；原 _InferenceWrapper 存在这一静态不一致，需要明确处理。
- 比较同样的确定性动作，不拿随机采样结果作逐元素等值比较。
- 仿真导出通过不等于真机验证；物理单位、关节顺序和运行周期仍需确认。
