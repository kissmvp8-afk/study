## 先让人看懂

保存和重复抽取过去的真实经历，同时保持时间关系和容量边界。

术语先说明：循环缓冲区：容量满后逐步覆盖最旧数据的存储方式。覆盖代次：用于区分旧槽位内容与新内容的标识。

## 必须成立的规则

- 第一版存编码前完整历史，暂不缓存会随编码器训练变化的隐藏特征。
- 循环覆盖后不能把末尾旧记录和新开头错误连接。
- 缓存容量须按实际字段字节数估算；500 万条不是 TITA 的默认保证值。
