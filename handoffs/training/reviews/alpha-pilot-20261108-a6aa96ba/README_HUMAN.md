# 这批试验回答了什么

这次修改把SAC计算中的alpha保留在GPU张量上。alpha的数值和更新方法保持原样，所以主要检验实现一致性与运行耗时。

核对后确认20组确实进行了参数更新，warmup为0。每对的训练日志和评价轨迹字节相同，但耗时差波动较大，尚未证实稳定提速。短训模型大多几乎不动，不能据此判断充分训练后的控制能力。

下一步仍建议从已有的R20完整恢复点执行原SAC-R3：一组保持当前alpha，另一组降到十分之一再继续学习。它检验学习强度，与本次检验计算载体不同。没有必要再增加同类短跑来重复验证当前结论。
