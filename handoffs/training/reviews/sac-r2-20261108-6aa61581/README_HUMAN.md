# 这轮结果说明什么

R20已经能在部分测试中跟踪前后速度，但停车仍有漂移和旋转。R21增加停车惩罚后，部分测试更好，另一些变差，还出现了早期跌倒，所以现在不能采纳它作为稳定改进。

我们独立算了46次评价的逐步数据，核对训练计数及实际停车惩罚，发现报告主要指标一致。同时发现训练日志把历史终止标记重复算成了当前事件；这个问题影响分项终止统计，已审阅的采集真实终止和冻结评价结果仍可用。下一轮要先修正这处日志。

下一轮从较稳定的R20同一个保存点出发：一组照常学习，另一组把当前温度alpha降低到十分之一，再继续自动学习。它们各新增2048轮，保持相同预算和其他参数。这样检验熵正则强度是否影响停车和随机控制，不用再次从零训练，也不在评价时人为压小动作噪声。

新门槛明确要求停车时既慢下来也少转动。开发测试通过后，再检查新的评价seed、左右转向和固定短脉冲恢复；更多评价seed不等于更多独立训练。
