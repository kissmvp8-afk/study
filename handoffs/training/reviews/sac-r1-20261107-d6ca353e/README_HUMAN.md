# 这次复审做了什么

我们把两份证据包合并并核对了文件指纹，独立计算了48次评价中的速度、停车、转向误差和提前终止时序，也核对了两组训练每一轮的更新次数。复算程序只读取原始数据，未在本机运行机器人仿真或训练。

SAC-R1的训练执行完成，但停车和航向仍未通过验收。增加站立指令比例带来部分改善，不能据此认为整个控制已经成功。S1的一次随机执行在零指令时加速并触地，原因需要进一步区分。

下一轮先冻结已有SAC模型，分别测试观测噪声和持续外力的影响。只有预先写明的条件满足，才开展两条等预算训练，比较加入停车速度惩罚是否有帮助；如果已有模型在降低持续外力的条件下已达标，则直接转去检验转向和短时抗扰，节省训练预算。降低难度的结果和原始复杂条件的结果分别报告。
