# 给4090服务器上的Codex/Dot

先读4090_RUN.txt。它要求把部署、训练、评价和资料归档一次接起来，正常阶段自动推进；遇到真实阻塞再一次说明，不让用户每轮传话。

新服务器的setup_4090.sh负责建立隔离Python环境、安装固定依赖、取回机器人源码与URDF/mesh，并实际运行CUDA及Isaac采集。smoke_runtime.py只证明物理环境能运行；后面仍须确认SAC更新和完整断点恢复。

质量预算沿用六条轨迹：两个方向各三条fork，4090最多同时跑四条，剩下两条补齐到同节点再比较。先解决启动停车，达标才加入转向与渐进外力。后期回退时保留早期选点，不只展示最后或最好的一条。

参数和完整交付清单都已写明。最后只交一个总索引，里面可找到模型、恢复点、曲线、逐例轨迹、失败窗口、视频、代码及远端回读证明。执行完成、仿真验收和实机能力分别陈述。
