# 给使用者的说明

把DOT_START_HERE.txt交给Dot即可。Dot先在已付费服务器上检查、接好现有训练入口，之后按固定规则自动训练和筛选，不用你每轮搬文件或挑模型。

第一轮六个方向，每个两条随机续训；后续保留三个、两个、一个方向。目标约9小时，包括准备、训练、评价及归档，最长9.5小时。可验证的故障、控制退化、磁盘或租期不足会提前停止，不用空跑时间凑时长。

依据是机器人有没有摔倒、能不能按正反指令行走、能否停车和保持航向，训练奖励不能决定胜负。最终再用新的评价种子检查转向和有限外力恢复。如果所有组都不达标，得到的是本批“相对较好”的候选，不能写成机器人已经训练成功。

这里已经提供参数、评分和预算程序，以及经过CPU模拟的调度器；GPU训练入口尚需Dot在你的服务器接入和验证。当前没有启动服务器训练，也没有修改你聊天使用的模型或定时巡检任务。
