# SAC-R4：128环境整夜逐级筛选

本批由用户授权，替代未执行的R3。目标约9小时、硬上限9.5小时，在固定矩阵内自动做6→3→2→1筛选。租期和机器状态由Dot启动前核对，不自动购买资源。

直接交接 [DOT_START_HERE.txt](DOT_START_HERE.txt)。完整规则见 [execution-plan.txt](execution-plan.txt)，参数见 [parameters.json](parameters.json)。

每方向两条匹配的随机续训轨迹1001/1002，继承同一个已训练R20的网络、优化器和统计。新建128环境经验池和任务计数，不冒充原16环境的精确恢复或两次独立从零训练。所有方向原生策略噪声开启、20%站立指令、重置外力清零、间隔推力关闭。扰动只在基础控制验证通过后做有限脉冲测试。

工具接口：

- `training_helpers.py`：受限R20暖启动、8个“16 Critic+16辅助”微循环、冻结经验池采样缓存；保持原R20每新增交互的学习密度。
- `budget.py`：从满池实测吞吐及真实租期选共同q，预留评价、恢复和归档时间。
- `selection.py`：从逐步物理数据重算控制指标，核对模型哈希、有效配置、相同训练量、冻结状态、种子及配对物理起点；输出晋级决策。
- `night_controller.py`：单GPU顺序队列、固定四轮、预算/磁盘保护、可选胜者追加块、故障状态和重复启动保护。需Dot接入现有worker；控制器本身不导入Torch/Isaac。
- `test_protocol.py`：CPU协议和模拟队列测试。

本地执行 `python -m unittest -v test_protocol.py`；这些测试验证评分、数据完整性、预算和调度逻辑，不验证CUDA、Isaac或实际控制表现。服务器须另做execution-plan中的真实短测。控制器/worker仍需在服务器执行前适配和联调，不能把本目录称作已经部署的训练系统。

输入版本固定于用户附件SHA和先前独立审阅：R2指纹`6aa61581…`，20组温度张量化包SHA256 `a6aa96ba781df82d324ee2633c429f1d6ccb510156e890256d0ebb5f127ad96b`。原始R2/pilot结果尚未绑定GitHub提交；本交接提交不能冒充实验结果版本。
