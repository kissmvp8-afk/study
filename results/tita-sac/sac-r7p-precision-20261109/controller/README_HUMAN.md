# R7P四路直接启动

生成器只核对固定文件、以同盘硬链接引用同一父模型（不改原件）并写配置，不再跑旧预检或旧预算门控。最新用户命令单独留档，科学参数不变。随后执行launch-command.json里的命令，四进程错峰初始化，16轮预填充到齐后共同学习48轮。

训练worker每5分钟保存可恢复点，24/48学习轮保存节点；控制器每30分钟记录四路配置身份、计数、状态和恢复点，完成或异常时也立即记录。备份由独立R7P脚本执行，不能把本地记录说成已上传。

12:45只是尽量完成目标，不用旧估算拦住已授权开训。租期14:15绝不续费，保留最后一分钟有序保存。非有限、OOM、计数错、文件变更和磁盘安全问题仍会停止四路。学习结束才另跑30例开发诊断，不叫独立验收。
