# 直接训练R7P并保留节点

四个worker是P0/P1各两个fork，全部从同一R6模型继承。旧-8停车惩罚和2–4秒指令保持不变，只有P1额外加入固定0.5停车精度项。经验池、SAC公式、学习率等都不变。

代码不另跑长预检，但真实第一步会核对奖励经理分解、旧新项和dt；每轮核对真实更新次数、数值有限性，继承时核对完整网络/优化器/统计。检查不通过会留住最近有效恢复点并报告错误，不能虚报继续。

16轮预填充后四worker一起开始学习，共48学习轮。24和48轮保存模型及完整恢复点，期间每5分钟保存最新完整状态。用户要求的节点信息保存在对应JSON和训练日志。收到停止信号或到达实际截止时，在安全宏轮边界保存退出。

这里的8项本地测试不是GPU训练通过。实际训练是否已启动、训练到哪一步、首步奖励是否通过，都以controller和运行时产生的真实文件为准。这个worker没有操作服务器或安排归档。
