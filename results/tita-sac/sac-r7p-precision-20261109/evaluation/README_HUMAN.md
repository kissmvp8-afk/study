# R7P终点评价说明

这是短时停车精度开发诊断，不是正式验收。固定父模型先跑六例，再让P0/P1两条fork各跑六例，共30例。新种子为141、142、143，每个都跑确定性D和保留原生std的随机S。原来12秒停、前进、停、后退指令和评分门槛完全不变。

同一个seed在所有模型、D/S之间都必须有相同完整物理初态。评价参数、BN和归一化统计必须冻结，原始每步动作、姿态、速度、接触等继续保存。摔倒是真失败，不换seed再跑；缺失窗口保持null，不补零。

比较时先看每个fork，再看较差fork及所有匹配seed。P1必须保留两fork存活/指令响应、移动精度与停车yaw，且通过数或停车速度达到计划中的改善条件，才报告值得另行验证的短时信号。两个fork趋势相反会单列inconsistent。无改善不等于证明奖励长期无用，有改善也不自动晋级或追加训练。留出、转向和脉冲均不运行。

训练是否立即开始由用户最新授权和控制器处理，本目录不重复旧预检阻塞。这里仅独立准备评价入口和CPU契约测试，不声称已经做过R7P GPU评价。
